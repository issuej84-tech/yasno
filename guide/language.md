# Справочник языка

[Документация Yasno](README.md)

## Файл и синтаксис

Компилятор принимает один файл `.ys` в UTF-8. На верхнем уровне объявляются функции `fn`, импорты `extern` и структуры `struct`. Функцию и тип структуры можно использовать до их объявления. Имена чувствительны к регистру. Идентификатор начинается с латинской буквы или подчёркивания и может содержать цифры после первого символа.

Простые инструкции завершаются переводом строки, точкой с запятой или закрывающей скобкой блока `}`. Вызовы, списки параметров, выражения в круглых скобках и индексы можно переносить. После бинарного оператора или знака присваивания также можно перейти на следующую строку. Однострочный комментарий начинается с `//`.

Зарезервированные слова — `fn`, `export`, `let`, `var`, `if`, `else`, `while`, `for`, `in`, `return`, `break`, `continue`, `true`, `false`, `struct`, `new`, `extern`. На верхнем уровне имена скалярных типов и `print` заняты. Двойные кавычки используются в именах импорта и экспорта, с экранированием по правилам JSON.

## Типы и литералы

| Тип | Значения | Примеры |
| --- | --- | --- |
| `i32` | Целые от −2³¹ до 2³¹ − 1 | `42`, `-7`, `0x2a` |
| `u32` | Целые от 0 до 2³² − 1 | `42u32`, `0xffu32` |
| `i64` | Целые от −2⁶³ до 2⁶³ − 1 | `-12i64`, `1_000_000i64` |
| `u64` | Целые от 0 до 2⁶⁴ − 1 | `42u64` |
| `f64` | Числа двойной точности IEEE 754 | `3.5`, `2.0`, `1e-3` |
| `bool` | Истина или ложь | `true`, `false` |
| `[T]` | Ссылка на массив элементов типа `T` | `new [i32](4)` |
| Имя структуры | Ссылка на объект с именованными полями | `Ship(7.5)` для `struct Ship { speed: f64 }` |

Десятичные и шестнадцатеричные целые без суффикса имеют тип `i32`. Числовые литералы разрешают подчёркивания между группами цифр. Для дроби с точкой укажите обе части, например `0.5` и `5.0`. Литерал за пределами своего типа компилятор отклоняет.

## Переменные и область видимости

```text
let batch: u32 = 20u32
var processed = 0u32
processed = processed + batch
```

`let` закрепляет значение за именем, `var` разрешает присваивание. Объявление требует начального значения. Без аннотации тип выводится из выражения справа, а явная аннотация проверяет совпадение типов. Внутренний блок может объявить локальное имя, совпадающее с именем во внешнем блоке. В одном блоке повторное объявление имени вызывает ошибку.

## Преобразования

Используйте имя целевого числового типа как функцию.

```text
let count = 7
let half = f64(count) / 2.0
let whole = i32(half)       // 3
let mask = u32(-1)          // 4_294_967_295
let large = i64(count)      // 7i64
```

При расширении целого сохраняется знаковое значение или дополняются нули по исходному типу. При сужении остаются младшие биты. Преобразование в целый тип той же ширины сохраняет биты и меняет интерпретацию знака. Преобразование в `f64` может округлить большое целое. Преобразование из `f64` отбрасывает дробную часть в сторону нуля и вызывает ловушку Wasm, если целая часть выходит за диапазон либо аргумент равен бесконечности или NaN. Для условий используйте сравнение вроде `count != 0`.

## Операторы

Бинарные операторы в порядке от низшего приоритета к высшему. Операторы одинакового приоритета группируются слева направо, так что `a - b - c` читается как `(a - b) - c`. Скобки меняют порядок.

| Операторы | Допустимые типы и результат |
| --- | --- |
| `\|\|` | `bool` → `bool` |
| `&&` | `bool` → `bool` |
| `\|` | Целый тип → тот же целый тип |
| `^` | Целый тип → тот же целый тип |
| `&` | Целый тип → тот же целый тип |
| `==`, `!=` | Одинаковые типы → `bool`. Для ссылок сравниваются адреса |
| `<`, `<=`, `>`, `>=` | Одинаковые числовые типы → `bool` |
| `<<`, `>>` | Целый тип → тот же целый тип |
| `+`, `-` | Числовой тип → тот же числовой тип |
| `*`, `/`, `%` | Числовой тип → тот же числовой тип. `%` применяется к целым |

Оба операнда должны иметь одинаковый тип. Для `f64` пишите `value * 2.0`. Для `u32` пишите `value << 2u32`. Унарный `-` работает со знаковыми целыми и `f64`, `!` с `bool`, `~` с целыми. Доступ к полю и индексу связывается раньше унарных операторов. В выражении `i < scores.length && scores[i] > 0` обращение к элементу выполняется только при истинном первом условии.

Сложение, вычитание и умножение целых оборачиваются по ширине типа. Целочисленное деление округляет к нулю. Деление или взятие остатка с нулевым делителем вызывает ловушку. Такая же ловушка возникает при делении минимального знакового целого на `-1`. Остаток для этого случая равен нулю. Для сдвига используется количество битов по модулю ширины типа. Знаковый `>>` заполняет освободившиеся биты старшим битом числа, беззнаковый заполняет их нулями.

Арифметика `f64` использует правила IEEE 754. Деление `1.0 / 0.0` даёт бесконечность, а `0.0 / 0.0` даёт NaN. Сравнение NaN с любым числом через `==`, `<`, `<=`, `>`, `>=` даёт `false`, а через `!=` — `true`.

## Функции

```text
fn clamp(value: i32, low: i32, high: i32) -> i32 {
    if value < low { return low }
    if value > high { return high }
    return value
}

fn main() {
    print(clamp(17, 0, 10))
}
```

У каждого параметра указывается тип. Функции с результатом используют `-> Тип` и явный `return значение`. Компилятор требует видимый путь возврата для каждой ветки, и один лишь `return` внутри цикла этого правила не выполняет. Функция без результата может закончиться на `}` или выполнить `return` без значения.

Параметры доступны как `let`. Скаляр передаётся по значению, массив или структура — по ссылке. На уровне файла разрешены прямые и рекурсивные вызовы. Результат вызова можно отбросить, записав вызов как отдельную инструкцию.

`fn main()` автоматически экспортируется и служит точкой входа команды `run`. У неё нет параметров и результата. Для остальных функций используйте `export fn имя(...)` или `export "имя-в-wasm" fn имя(...)`. `print(value)` принимает один скаляр и возвращается без результата.

## Ветвления и циклы

```text
fn classify(n: i32) -> i32 {
    if n < 0 {
        return -1
    } else if n > 0 {
        return 1
    } else {
        return 0
    }
}

fn main() {
    var total = 0
    for n in 0 .. 20 {
        if n % 2 != 0 { continue }
        if n == 10 { break }
        total = total + n
    }
    while total < 25 {
        total = total + 1
    }
    print(classify(total))
}
```

`if` и `while` требуют условие типа `bool`. `while` проверяет его до первого прохода и после каждой итерации. `while true` можно завершить через `break` или `return`. `for name in start .. end` один раз вычисляет обе границы в порядке записи. Они должны иметь одинаковый целый тип. Переменная цикла неизменяема и доступна в его теле. Цикл повышает значение на единицу, исключает верхнюю границу и пропускает тело при `start >= end`. `break` выходит из ближайшего цикла, `continue` переходит к следующей итерации. Ветвления, циклы и присваивания используются как инструкции. Для обновления счётчика пишите `i = i + 1`.

## Границы текущей версии

Строковые значения, глобальные переменные Yasno, модули исходников, функции как значения, обобщённые типы, литералы массивов и стандартная библиотека файлового или сетевого ввода-вывода пока отсутствуют. Для взаимодействия с внешней средой объявляйте `extern`. Для запуска нескольких модулей связывайте их через приложение. [WebAssembly и JavaScript](wasm.md)
