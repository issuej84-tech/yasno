## Массивы

Тип `[T]` — ссылка на массив элементов одного типа. `new [T](n)` выделяет массив фиксированной длины. Длина и индекс имеют тип `i32`. Первый индекс — `0`, последний — `array.length - 1`. Поле `.length` доступно для чтения. Отрицательный индекс, индекс за границей, отрицательная длина или слишком большое выделение останавливают выполнение с ловушкой Wasm.

```text
fn sum(scores: [i32]) -> i32 {
    var total = 0
    for i in 0 .. scores.length {
        total = total + scores[i]
    }
    return total
}

fn main() {
    let scores = new [i32](3)
    scores[0] = 10
    scores[1] = 20
    scores[2] = 30
    print(sum(scores))
}
```

Результат — `60`. Версия с экспортами позволяет прочитать те же данные из JavaScript. [scores.ys](../examples/guide/scores.ys) · [Чтение памяти из Node.js](wasm.md#чтение-массива-из-памяти)

Числа начинаются с нуля, а `bool` с `false`. Элемент ссылочного типа изначально содержит нулевой адрес. Заполните его перед доступом к полям, длине или элементам. Индексирование пустого массива вызывает ловушку. Перебор через `0 .. array.length` безопасно выполняет ноль итераций для пустого массива.

## Структуры

```text
struct Point {
    x: f64
    y: f64
}

struct Route { points: [Point], visible: bool }

fn main() {
    let points = new [Point](2)
    points[0] = Point(1.0, 2.0)
    points[1] = Point(3.0, 4.0)
    let route = Route(points, true)
    route.points[1].x = 8.0
    print(points[1].x)
}
```

Объявите поля с именами и типами. Запятые или переводы строки разделяют поля. Конструктор `Имя(...)` принимает по одному значению для каждого поля в порядке объявления. Поле читают и изменяют через точку. В этом примере обе переменные обращаются к одному массиву, поэтому программа выводит `8`.

Массивы могут содержать структуры и другие массивы. Например, для `new [[i32]](2)` внутренние массивы создаются отдельными вызовами `new [i32](n)` и могут различаться по длине. Присваивание, передача параметра и возврат из функции копируют только ссылку. Сравнение двух ссылок показывает, указывают ли они на один адрес.

## Срок жизни и повторное использование

Память привязана к экземпляру WebAssembly и может вырасти до 64 МиБ. Каждое выделение отводит новый участок. Выход из функции и потеря последней ссылки место не возвращают. Для длительных вычислений выделяйте массивы перед главным циклом и заполняйте их повторно. Когда прежние данные больше не нужны, приложение может создать новый экземпляр и отпустить ссылки на прежний экземпляр и его память.

Ссылку, полученную от экспорта, передавайте обратно в тот же экземпляр. Новая загрузка одного и того же файла Wasm создаёт отдельную память. Передавайте через границу только значения допустимого типа и адреса, выданные этим экземпляром.

## Формат в памяти Wasm

Все смещения относятся к началу линейной памяти. Многобайтовые значения хранятся в little-endian.

| Объект | Представление |
| --- | --- |
| Ссылка | `i32` со смещением в байтах. Адрес `0` зарезервирован |
| Заголовок массива | Первые 4 байта — длина как `i32`. Первому элементу предшествуют 8 байт заголовка |
| Элемент `i32`, `u32`, `bool` или ссылка | 4 байта |
| Элемент `i64`, `u64` или `f64` | 8 байт |
| Поле структуры | Ячейка 8 байт по порядку объявления. 32-битное значение занимает первые 4 байта ячейки |

Начало каждого выделения выровнено на 8 байт. Для массива смещение элемента `i` вычисляется как `pointer + 8 + i * stride`, где `stride` равно ширине элемента в байтах. Для структуры смещение поля `i` равно `pointer + i * 8`. Если вызов мог увеличить память, создайте новое представление `DataView` или типизированный массив поверх текущего `memory.buffer`.
