# Документация Yasno

Yasno компилирует исходники `.ys` в WebAssembly. На языке можно писать функции для численных расчётов, обработки массивов и обновления состояния. Программу можно запускать из командной строки или вызывать её функции из приложения.

## С чего начать

| Задача | Раздел |
| --- | --- |
| Установить компилятор и запустить первую программу | [Быстрый старт](start.md) |
| Найти синтаксис, тип, оператор или правило преобразования | [Справочник языка](language.md) |
| Хранить состояние и работать с массивами и структурами | [Массивы, структуры и память](memory.md) |
| Вызвать Yasno из JavaScript или передать в Yasno функцию приложения | [WebAssembly и JavaScript](wasm.md) |
| Проверить файл, собрать модуль или разобраться в ошибке | [Команды и диагностика](cli.md) |
| Воспроизвести замеры скорости калькуляторов Yasno и Rust | [Команды и результаты теста](../README.md#калькулятор) |
